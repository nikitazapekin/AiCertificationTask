# Atlassian Integration

Spawn atlassian-skill agent to integrate with Jira and Confluence.

## Input
$ARGUMENTS

## Instructions

Use the Task tool to spawn a sub-agent:
- **subagent_type:** `atlassian-skill`
- **description:** `Atlassian integration`
- **prompt:** `$ARGUMENTS`

The agent will use the atlassian-skill skill and suggest next steps when done.
